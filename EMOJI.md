# Animated emoji

The web composer and message view support 631 animated emoji. Open the smile button beside the message field, search by English name or scroll the complete catalog. The editor stores text tokens in messages, so older or native clients may show those tokens. Files are served from `assets/animated-emoji/` on the same site. The browser loads images as needed.

The artwork comes from [Telegram Animated Emojis](https://github.com/Tarikul-Islam-Anik/Telegram-Animated-Emojis); the upstream [license](https://github.com/Tarikul-Islam-Anik/Telegram-Animated-Emojis/blob/main/License) states personal use only. The project owner reported separate authorization; it does not grant downstream users rights. Obtain any authorization needed for your own use and distribution. These optimized WebP files retain animation.
